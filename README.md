# Slovo Listen

Live Russian → English captions with speaker labels, for following family conversations at the table.

- Runs entirely in the phone's browser; audio streams straight to Soniox (real-time STT + translation + diarization).
- The Soniox API key is entered in Settings and stored only on the phone (localStorage). It is never committed here.
- Open on iPhone in Safari → Share → Add to Home Screen.

## Microphone tips
- Settings → Microphone: pick a USB mic (or the iPhone mic). If earbuds are connected, iPhone otherwise switches to the earbud mic, which mostly hears the wearer.
- Auto volume is off by default; turn it on only if voices are very quiet.
- A web page can't listen with the screen locked. The page keeps the screen awake and picks the mic back up when you return; for long sessions set Auto-Lock → Never (Low Power Mode blocks the keep-awake request).
