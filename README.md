# Slovo Listen

Live Russian → English captions with speaker labels, for following family conversations at the table.

- Runs entirely in the phone's browser; audio streams straight to Soniox (real-time STT + translation + diarization).
- The Soniox API key is entered in Settings and stored only on the phone (localStorage). It is never committed here.
- Open on iPhone in Safari → Share → Add to Home Screen.
